# 遊戲庫

## 結構

```
games/
  <game-id>/
    README.md        遊戲說明、目前版本、來源點子
    v1/              可直接遊玩的版本（index.html 等）
    v2/
    ...
```

## 版本規則

- 每次發佈給測試者的版本都要有獨立資料夾，舊版本保留，不刪除。
- 每個發佈版本在 git 中打 tag，格式為 `<game-id>-v<版號>`。
- 每個版本資料夾的 README 或 changelog 要記錄：改了什麼、為什麼改、對應的假設是什麼。
- 評分表的每一筆都要對應到 `<game-id>` 與版本號。

## 首頁（遊戲庫）

- 顯示所有遊戲卡片：名稱、目前版本、更新日期、一句話簡介。
- 「最近更新」區塊列出近期的版本與新遊戲。
- 每款遊戲提供「開始玩」與「給回饋」連結。

## 一款遊戲的 README 格式

```
# <遊戲名稱>

- **來源點子**：ideas/ 中的檔案路徑
- **目前版本**：v?
- **狀態**：實驗中／已擱置／已發佈
- **玩法摘要**：兩三句話
- **面向自由度**：（沿用來源點子的表格）
```
