# 前線輪替

- **來源點子**：ideas/seeds/front-line.md
- **目前版本**：v3（Claude 自我迭代，尚無人類評分；v2 保留可比較）
- **狀態**：已擱置（2026-11-28：你表示先換題目，非否定，之後可回來；v3 尚無人類評分）
- **題材**：軍隊防線
- **核心機制**：疲勞輪替、推進防守、兵種特性（v1 為屬性剋制）
- **玩法摘要**：敵軍逐回合逼近。每回合只能派上或撤下一名士兵；戰鬥累積疲勞，後方休息恢復並訓練。要決定誰頂上、誰撤下。
- **面向自由度**：沿用來源點子

## 版本紀錄

### v1

- **改了什麼**：第一版。取代「流動平衡」的同時暗選骨架。
- **為什麼**：你指出流動平衡本質像猜拳。
- **假設**：公開資訊加上疲勞輪替，能讓「多想一步」明顯有用，玩家感受到取捨而不是賭運氣。

### 模擬（`scripts/sim/front-line-sim.js`，代理指標，不代表好不好玩）

模擬玩家：「眼前」會窮舉本回合指令並取最好；「前瞻」再往後推演 3 回合（只看場上已出現的敵人）。

看結果前定義的標準，以及 v1 在兩組未用於調參的種子上的結果（各 150 局）：

| 標準 | 結果 |
|---|---|
| 前瞻勝率比眼前高 25 個百分點以上 | 73–77% 對 21–27%，通過 |
| 眼前勝率 10–55% | 21–27%，通過 |
| 前瞻勝率 55–90% | 73–77%，通過 |
| 亂下勝率 ≤ 5% | 0%，通過 |
| 只派人不撤下勝率 ≤ 15% | 0%，通過 |
| 前瞻與眼前選擇不同的回合 ≥ 30% | 33%，通過（接近門檻） |

調參過程：

- 初版參數太簡單，眼前玩家勝率 100%。
- 每回合 2 個指令的版本也能全部通過，而且深度指標更高（前瞻 84% 對眼前 16%，選擇不同 45%）。仍採用 1 個指令，理由是每步較好思考、取捨較清楚。這是判斷，不是數據支持的結論，可用試玩比較。
- 模擬器曾有錯誤（1 指令時「眼前」玩家仍下 2 個指令），修正後重跑，以上為修正後數據。

### 已知限制

- 模擬玩家比真人算得完整，真人勝率很可能更低，第一次玩可能覺得難。
- 「只派人不撤下」的模擬策略很陽春，0% 的參考價值有限。
- 節奏、成就感、是否算起來太累，量不到。

### v1 補充（2026-11-26）：犧牲規則

- **改了什麼**：規則不變。預測畫面加上「敵剩 X」，說明文字寫清楚落敗時敵人會扣多少。因為 v1 還沒發佈給測試者，直接改在 v1。
- **為什麼**：原畫面只顯示「陣亡」，玩家無法把犧牲當戰術使用。
- **模擬對照**（兩組種子各 150 局，前瞻玩家）：

| | 有犧牲規則 | 無（落敗即漏敵） |
|---|---|---|
| 前瞻勝率 | 73–77% | 47% |
| 眼前勝率 | 21–27% | 8–12% |
| 前瞻與眼前選擇不同的回合 | 33% | 25–26% |
| 主動派必敗士兵擋敵（每局） | 0.60–0.73 次，56–63% 的局有用到 | 0 次 |

- **解讀與限制**：模擬中這條規則確實被拿來用。拿掉後沒有重新調整難度，所以勝率與深度指標的差異混有難度因素，不能單獨歸功於這條規則。
- **決定**：保留（你同意）。

### v2（2026-11-26）

- **依據**（你試玩 v1）：比流動平衡有策略性；每回合只下一步卻要另按結束回合，操作有點卡；建議兵種改成真實特性，不只互相剋制。
- **改了什麼**：
  - 操作：派兵或撤下後立刻結束回合。撤下需連點兩次以防誤觸；原「結束回合」改為「待命」。移除「取消指令」。
  - 移除剋制。敵人只剩戰力數字。
  - 盾兵：疲勞係數 0.2（其他兵種 0.5）。騎兵：剛上陣第一場 +6。弓兵：基礎 6，在前線射擊最近兩格的接近敵人，傷害為戰力一半，每箭疲勞 +1。
  - 敵人後期戰力上限 11 改 12。
- **假設**：兵種特性讓「派誰」比剋制更有取捨；操作變順但不增加誤觸。
- **模擬**（`scripts/sim/front-line-v2-sim.js`，兩組未調參種子各 150 局）：
  - 原 6 項標準全部通過：前瞻 75–77%、眼前 23–31%、亂下 0%、只派不撤 0%、選擇不同 32–33%。
  - 看特性結果前追加的兩項：
    - 各兵種占派兵次數 ≥ 15%：通過（盾 50–52%、騎 27–28%、弓 21%）。
    - 拿掉任一特性，前瞻勝率變化 ≥ 10 點：盾 8–10、騎 16–18、弓 11–12。**盾兵在一組種子差 2 點未過。**
  - 第一輪（衝鋒 +5、盾 0.25）掉幅只有 3–11 點，之後才加強特性並提高敵人戰力。
- **已知問題**：
  - 後方士兵 3 回合就訓練到上限，開局後訓練幾乎不構成取捨（v1 就有）。
  - 盾兵派兵占比過半，可能是太好用。
  - 模擬量不到操作手感。

### v2 補充（2026-11-26）：難度分級

- **依據**：你試玩 v2 後回饋「難度好高」。
- **改了什麼**：加入三段難度，預設簡單；原本的數值成為「困難」。只改敵人數量、敵人戰力與防線耐久。切換難度會開新局。代號為 FL-2E／FL-2N／FL-2H。v2 尚未發佈給測試者，因此直接改在 v2。

| 難度 | 耐久／後期敵數／後期戰力 | 「只看本回合」模擬勝率（150 局） |
|---|---|---|
| 簡單 | 4／1.6／10 | 95% |
| 普通 | 4／1.8／11 | 62% |
| 困難 | 3／1.8／12 | 約 23–31% |

- **限制**：模擬玩家會窮舉本回合指令，真人勝率會更低。先前 8 項標準只在「困難」數值上檢驗過，簡單與普通不保證有同樣的策略深度。
