# 遊戲實驗室：總覽

## 實驗目的

1. **探索型**：透過反覆的設計、試玩與人類評分，找出「好玩」遊戲的設計準則。
2. **作品型**：實作一些臨時想到的點子，累積可以重複遊玩的遊戲版本。

兩者同等重要。準則需要依據遊戲版本的評分來建立；遊戲版本也需要準則來指引改進方向。

## 閱讀順序

1. `ideas/README.md`：點子的三層分類與自由度規則
2. `rubric.md`：評分標準（唯讀，改動需要人工批准）
3. `evaluation.md`：試玩、盲測與決策規則
4. `principles/README.md`：設計準則的格式與目前狀態
5. `games/README.md`：遊戲庫的結構與版本規則
6. `open-questions.md`：尚未決定的事項

## 目錄結構

```
README.md            本文件
ideas/               點子收件箱（三層）
principles/          設計準則
games/               遊戲與版本
rubric.md            評分標準
evaluation.md        評分流程與決策規則
open-questions.md    未決事項
```

## 核心原則

- 每個版本都是一次假設測試，應該能說清楚想驗證什麼。
- 點子的來源與每個設計決定的歸屬必須可追溯：哪些是你決定的，哪些是 Claude 補的。
- 自由度依「面向」設定，不是依「點子」整體設定。
- 評分標準由人控制，AI 不得自行修改。
