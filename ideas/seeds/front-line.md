## 由 Claude 補完的設定（v1）

| 項目 | 內容 |
|---|---|
| 棋盤 | 5 欄，敵軍區 4 列加 1 列前線，回合制 |
| 部隊 | 8 名士兵（▲3、■3、●2），基礎戰力 8 |
| 戰力 | 基礎 + 訓練 − 疲勞，沒有血量 |
| 交戰 | 戰力不低於敵人則勝，疲勞 += 敵人戰力 × 0.5（無條件進位）；剋制方 ×1.5 |
| 陣亡 | 落敗的士兵永久死亡，敵人扣掉士兵戰力的一半後留在原地（讓犧牲也是一種選擇） |
| 後方 | 每回合恢復 4 疲勞；無疲勞時訓練 +1，上限 +3 |
| 指令 | 每回合 1 個：派上（可直接換班）或撤下 |
| 勝負 | 撐過 14 波並清光敵人獲勝；漏掉 3 個敵人失敗 |
| 資訊 | 場上敵人全公開，另預告下一波；派兵前顯示勝負與疲勞預測；沒有交戰運氣 |
| 隨機 | 只有每局的敵人序列 |
