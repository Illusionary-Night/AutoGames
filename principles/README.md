# 設計準則

這裡記錄從試玩與評分中歸納出的設計準則。每條準則都要說明依據與信心等級，避免把單一結果當成定論。

## 信心等級

| 等級 | 條件 |
|---|---|
| 假說 | 只在單一版本或單一測試中觀察到 |
| 初步支持 | 在兩款以上遊戲或多個版本中出現，但樣本仍少 |
| 穩定 | 經過盲測，且在多款遊戲中一致 |
| 已推翻 | 後續資料與此準則矛盾，保留紀錄但標示 |

## 單條準則的格式

```
## [準則標題]

- **陳述**：一句話描述準則
- **信心等級**：假說／初步支持／穩定／已推翻
- **依據**：對應的遊戲版本與評分資料
- **反例或限制**：已知不適用的情況
- **最後更新**：日期
```

## 目前狀態

## 勝負不應主要取決於猜對手的隱藏選擇

- **陳述**：雙方同時暗選、玩家難以利用資訊時，策略遊戲會感覺像猜拳。
- **信心等級**：假說
- **依據**：auto-balance v1，1 位試玩者（使用者）的文字評語。模擬也顯示：只挑最大數字的玩家勝率 63.4%，另考慮剋制者 65.9%，差距很小。
- **反例或限制**：單一遊戲、單一試玩者。有些遊戲的樂趣正來自心理博弈（需要能讀對手的資訊）。
- **最後更新**：2026-11-26

## 解謎關卡不應留下用不到的資源

- **陳述**：給的步數或資源多於解法所需時，玩家會覺得該關偏簡單、缺少推理壓力。
- **信心等級**：假說
- **依據**：rune-lab v1，1 位試玩者（使用者）的文字評語。第 7、8 關上限 3、2 次但 1 次可解，被認為比第 6 關（必須 2 次）簡單；第 7、8 關的隨機亂試成功率並不全比第 6 關高，所以亂試成功率不足以代表難度。
- **反例或限制**：單一遊戲、單一試玩者。偏休閒的解謎可能需要寬裕資源。
- **最後更新**：2026-11-28
