# Google Forms 建立說明

照著下面建一份表單即可。所有遊戲共用同一份表單，用「遊戲代號」區分。

## 表單設定

- **表單標題**：遊戲實驗室回饋
- **表單說明**：貼上 `feedback/notice.md` 的整段文字。
- **設定 → 回覆**：
  - 「收集電子郵件地址」：**關閉**
  - 「限制每人只能回覆一次」：**關閉**（需要登入，且同一人要能評多款遊戲）
  - 「傳送回覆副本」：關閉
- **設定 → 簡報**：「顯示進度列」開啟即可。

## 題目

| # | 題目文字 | 類型 | 必填 | 備註 |
|---|---|---|---|---|
| 1 | 你的暱稱 | 簡答 | 是 | 說明文字：「請用不太常見的暱稱，之後如果想刪除回答，告訴我這個暱稱即可。」 |
| 2 | 遊戲代號 | 簡答 | 是 | 說明文字：「在遊戲畫面上可以看到，請照抄。」 |
| 3 | 這是你今天玩的第幾個遊戲？ | 選擇題（單選）：1、2、3、4、5 以上 | 是 | 用來檢查順序效應，見 `evaluation.md` |
| 4 | 第一次玩時，是否容易開始？ | 線性刻度 1–5 | 是 | 左標籤「很難上手」，右標籤「馬上就會」 |
| 5 | 操作後，遊戲有沒有給你明確的反應？ | 線性刻度 1–5 | 是 | 左「完全感覺不到」，右「非常明確」 |
| 6 | 失敗後想再試嗎？成功時有成就感嗎？ | 線性刻度 1–5 | 是 | 左「失敗很煩、成功沒感覺」，右「失敗想重來、成功很爽」 |
| 7 | 你想再玩一次嗎？ | 線性刻度 1–5 | 是 | 左「完全不想」，右「很想」 |
| 8 | 整體而言，你喜歡這個遊戲嗎？ | 線性刻度 1–5 | 是 | 左「很不喜歡」，右「很喜歡」 |
| 9 | 最喜歡的地方是什麼？ | 段落 | 否 | 說明文字：「沒有也沒關係，寫幾個字就好。」 |
| 10 | 最不喜歡的地方是什麼？ | 段落 | 否 | 說明文字：「想到什麼就寫，直說比客氣更有幫助。」 |

## 對應關係

第 4–8 題對應 `rubric.md` 的五個評分面向（上手難度、回饋感、挫折與成就的節奏、再玩意願、整體喜好），順序相同。如果 `rubric.md` 之後有修改，這份說明要一併更新。

## 建好之後

1. 右上角「傳送」→ 連結分頁，複製網址（可以勾「縮短網址」）。
2. 把網址填進 `games/games.json` 的 `feedbackFormUrl`。
3. 回應分頁 → 連結到試算表 → 下載 CSV，存到 `feedback/<game-id>-v<版號>.csv`。
